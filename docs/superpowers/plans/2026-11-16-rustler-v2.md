# Rustler v2 Implementation Plan (Phase 0 detailed, Phase 1 tasks, Phases 2–3 outlined)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2 in phases: quick wins (v0.1.2), then the open timeline + agent templates/assets/references/posting JSON foundation (v0.2.0), then the director layer + smooth camera + OpusClip-quality features (v0.3.0), then automation/GUI/skills (v0.4.0).

**Architecture:** Storage stays `clips/<id>/clip.json` + `extras.json` (v1, frozen); **timeline v2 is the canonical document interface** assembled from and written back to that storage by one module, so every v1 command keeps working and no migration is needed (refines design §5.1 / builder-check Q1). New layer kinds live under new `extras.json` keys. All new behaviour is registry commands; the compiler renders new layers in the same single graph.

**Tech Stack:** Rust (existing crates), `json-patch` crate (RFC 6902), `tiny-skia` + `ab_glyph` for cards, Python engine (light measures only), FFmpeg.

**Spec:** `docs/superpowers/specs/2026-11-16-rustler-v2-design.md`

## Global Constraints
- No AI API calls anywhere; the driving agent makes judgement calls (titles, hooks, moments, style).
- Lite install stays lite: nothing new is heavy by default; heavy features opt-in via `setup run --with`.
- Never publish/upload/post output. No stock-footage or AI APIs.
- v1 commands and project files keep working; frozen contracts are only *extended* with optional fields.
- One FFmpeg encode per deliverable; 9:16 1080×1920 only.
- Every JSON-taking command accepts `--input-json @file` (PowerShell 5.1 strips quotes).
- Windows: cargo from PowerShell, `$env:CARGO_BUILD_JOBS=2`, max 4 parallel agents (16 GB RAM).
- Git: default branch `main`; origin is HTTPS (SSH blocked). Agents commit in their worktree branch; orchestrator merges + pushes.
- After each merge: `docs/progress-log.md` entry; feature file status; knowledge guides updated for new commands.

## Review Focus
1. Stale edits: two writers (GUI + agent) apply patches with the same `base_revision` → second gets `revision_conflict`, nothing lost (Task 1.2 test `apply_stale_revision_conflicts`).
2. Old v1 projects (clips without new extras keys, packs from v0.1.x) open in `timeline.show` with empty new tracks (Task 1.1 test `assemble_v1_clip_has_empty_new_tracks`).
3. A template applied on another machine references a missing font/asset → clear `not_found` naming the asset, or a bundled copy via `template.import` (Task 1.5 test `apply_missing_asset_errors_with_name`).
4. Word-anchored items (caption overrides, SFX, effects) after a re-cut that removes their word → dropped with a warning, never placed at a wrong time (Task 1.3 test `anchor_removed_by_recut_is_dropped_with_warning`).
5. Large patches touching many layers render with correct z-order: masks < captions < text < images by `z` (Task 1.3 test `layer_z_order_in_graph`).

## Phase 1 — foundation (v0.2.0)

### Task 1.1 (Opus, first, frozen after): Timeline v2 contract + assemble/disassemble
**Files:** Create `crates/rustler-core/src/model/timeline.rs`, `crates/rustler-commands/src/timeline_doc.rs`; tests `crates/rustler-core/tests/timeline.rs`, `crates/rustler-commands/tests/timeline_doc.rs`.
**Interfaces — Produces:**
```rust
// rustler-core (serde + JsonSchema), schema id "rustler.timeline@2"
pub struct Timeline { schema, id: ClipId, name, revision: u64, canvas: Canvas, template_ref: Option<TemplateRef>,
  tracks: Tracks, meta: TimelineMeta }
pub struct Tracks { video: Vec<VideoSeg>, cutaways: Vec<Cutaway>, images: Vec<ImageLayer>, masks: Vec<MaskLayer>,
  text: Vec<TextLayer>, captions: CaptionsTrack, audio: AudioTrack, effects: Vec<EffectItem>,
  transitions: Vec<TransitionItem>, progress_bar: Option<Value> }
pub struct Anchor { source_id: SourceId, word_i: u32 }       // word-anchored timing
pub enum When { Out { start: f64, end: f64 }, Words { from: Anchor, to: Anchor } }
// rustler-commands::timeline_doc
pub fn assemble(store: &ProjectStore, clip: &ClipId) -> Result<(Timeline, Vec<String> /*warnings*/)>;
pub fn disassemble(store: &ProjectStore, t: &Timeline, base_revision: u64) -> Result<u64 /*new revision*/>;
```
Field names follow design §5.1 exactly; new layers stored in `extras.json` keys `cutaways, images, masks, text_layers, caption_word_overrides, meta` (existing keys `overlays, music, sfx, effects, transitions, progress_bar, crop_paths, audio_fx` map 1:1).
- [ ] Tests: `assemble_v1_clip_has_empty_new_tracks`, `roundtrip_assemble_disassemble_is_identity` (clip with every v1 feature), `schema_generates`. Commit; announce frozen.

### Task 1.2: timeline.show / schema / apply
**Files:** `crates/rustler-commands/src/timeline_cmds.rs` (+lib.rs), tests `tests/timeline.rs`. Dep: `json-patch`.
**Interfaces:** `timeline.show {clip_id}` → Timeline + resolved times; `timeline.schema {}`; `timeline.apply {clip_id, base_revision, patch?: [JSON-Patch ops], document?: Timeline}` → validate (rects 0–1 & w,h>0.02; times within duration; assets/sources exist; anchors resolve; z ints) → disassemble → `{revision, document, changes:[…], warnings}`; `--dry-run` validates only. History snapshots both files (undo covers all layers).
- [ ] Tests: `apply_patch_moves_overlay`, `apply_stale_revision_conflicts`, `apply_invalid_rect_validation_lists_path`, `apply_document_replace`, `undo_restores_layers`. Commit.

### Task 1.3 (Opus): Compiler — new layers
**Files:** `crates/rustler-media/src/{compile.rs,layers.rs}` + tests. Consumes Timeline types (via CompileExtras additions).
Renders: masks (boxblur/drawbox/pixelate within rect & time), image layers (overlay with scale/opacity/fade anim, PNG/JPG/GIF loop), text layers (ASS with styles; same overlays.ass path), cutaways (full: replace video in range with media fitted cover; pip: overlay rect), caption word overrides (color/scale/emoji/hide in ASS). Z-order: video → cutaway(full) → masks → images/text by z → captions on top unless a layer has `above_captions`.
- [ ] Tests: graph tests per layer, `layer_z_order_in_graph`, `anchor_removed_by_recut_is_dropped_with_warning`; real renders + LOOK at frames (mask hides a box, logo PNG at corner, PiP cutaway). Commit.

## Phase 2 (v0.3.0) — director + smooth camera + quality (detailed plan written after Phase 1)
Director: `campaign.analyze`, `clip.retention` (retention map + score + dead zones), playbook guides + hook lab prompt, `edit.cold_open`, `clip.score set`. Smooth camera: offline trajectory planner (velocity/accel limits, dead zone, anticipation, hold-or-move), look-room, light active speaker default, per-scene `layout.plan`, dark-footage scene cuts, motion QC. Quality: smart defaults at `clip.create` (`--raw` off), filler/bad-take cleanup, hook presets (animated, 5+ styles), keyword/emoji captions, caption auto-position + burned-in band detection, flash/whip transitions, weak-visual detector, `clip.cover`.

`clips.auto` wrapper, GUI for new tracks/templates/references/post JSON/campaigns, knowledge refresh, release, side-by-side trial vs clips-trial-1.
